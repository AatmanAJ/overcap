# Support

Start with the [installation guide](docs/install.md) and the provider guide linked from the
[README](README.md).

## Report a problem

[Open a bug report](https://github.com/AJ-Base44/overcap/issues/new?template=bug_report.yml) and
include:

- Your Overcap version
- Operating system, version, and architecture
- Installation type, such as NSIS, DMG, AppImage, or Debian package
- The affected provider, if any
- Short reproduction steps and what you expected to happen

Screenshots and reviewed log excerpts can help. Remove credentials, access tokens, account
identifiers, file paths, and other private data before posting.

For setup questions that do not fit the issue form, email
[aj@seebyond.com](mailto:aj@seebyond.com).

## Security problems

Do not report a vulnerability in a public issue. Follow the private process in
[SECURITY.md](SECURITY.md).

## Provider outages and account limits

Overcap displays data supplied by the connected provider. It cannot change a provider's limit,
reset an account, or resolve a provider outage. Check that provider's status and support channels
when the same problem appears in its own tool or dashboard.
