# Overcap website

The public marketing, download, privacy, and support site for
[Overcap](https://github.com/AJ-Base44/overcap).

## Commands

```sh
npm install
npm run validate
npm run dev
npm run build
```

The site is built with vinext for OpenAI Sites. It has no database, sign-in, analytics, telemetry,
or client-side data collection.

## Launch media

Place privacy-safe launch assets in `public/media/`:

- `overcap-demo.webm`
- `overcap-demo.mp4`
- `overcap-dashboard.png`
- `overcap-social.png` (1200×630)

Use synthetic usage data only. Never show credentials, account names, local paths, API tokens, or
personal notification content.
